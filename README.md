# pipasila.ru — сайт бренда PIPA 🧢

Официальный сайт бренда **PIPA** — уличные кепки и шапки из Казани. Репозиторий содержит статический сайт на чистом **HTML/CSS/JavaScript** с акцентом на скорость, аккуратную типографику и базовую SEO-обвязку.

---

## 🏷️ О бренде

**PIPA** — уличный бренд головных уборов из Казани: кепки, шапки и аксессуары в городском стиле.

Цели сайта:
- представить бренд и коллекции;
- быстро и красиво показывать контент на мобильных устройствах;
- быть понятным для поисковых систем (robots/sitemap, корректные мета-теги).

Технологический принцип: **без тяжёлых фреймворков** — минимализм в коде, максимум контроля.

---

## 🧰 Технологии

- **HTML / CSS / JavaScript (vanilla)**
- Шрифты: **Inter**, **Barlow**, **Bebas Neue**
- SEO:
  - `robots.txt`
  - `sitemap.xml`
  - мета-теги и корректная структура страниц
- Хостинг: **GitHub Pages** (бесплатно)
- Домен: pipasila.ru (DNS-записи у регистратора / в Cloudflare в режиме «DNS only»)
- Сайт **не собирает персональные данные**: нет форм, бэкенда, cookies и аналитики. Все покупки — на Ozon и во ВКонтакте.

## 🚀 Установка (локальный запуск)

Сайт статический — сборка не требуется.

### Вариант 1: открыть файл напрямую

Можно открыть `index.html` в браузере, но часть вещей (например, `fetch` или некоторые пути) может работать иначе из-за ограничений `file://`.

### Вариант 2 (рекомендуется): поднять локальный сервер

**Python:**
```bash
python3 -m http.server 8080
```
Откройте: `http://localhost:8080`

**Node.js (если установлен):**
```bash
npx serve .
```

## 🗂️ Структура проекта

Точная структура может отличаться — ниже типовая схема для этого репозитория:

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── img/
│   └── fonts/
├── robots.txt
├── sitemap.xml
└── (доп. страницы) about.html, catalog.html, ...
```

Рекомендации по поддержке структуры:
- изображения хранить в `assets/img/` и использовать понятные названия файлов;
- шрифты/подключения держать централизованно;
- не раздувать `main.js`: выносить модули/функции по смыслу, если проект растёт.

## 📦 Деплой (GitHub Pages)

1. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Custom domain: `pipasila.ru` (файл `CNAME` уже лежит в репозитории), затем включить **Enforce HTTPS**.
3. DNS для `pipasila.ru`:
   - 4 записи `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www` → `<github-логин>.github.io`
   - В Cloudflare у этих записей должно быть серое облако («DNS only»).
4. Любой коммит в `main` публикуется автоматически за 1–2 минуты.

Фото текущего дропа лежат в `images/pipa-gym-drop.jpg`, `pipa-mafia-drop.jpg`, `pipa-7-drop.jpg` — чтобы заменить, загрузите файлы с теми же именами.
